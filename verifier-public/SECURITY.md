# Security Policy

## Supported Versions

The offline verifier supports verifying evidence files generated by any release of LedgerSeal v2.x.

| Version | Supported |
|---|---|
| 1.0.x | Yes |

## Reporting a Vulnerability

Asymm Systems takes cryptographic integrity and security vulnerabilities seriously.

If you believe you have discovered a vulnerability in the offline verifier, canonicalization engine, or signature verification mechanics:

1. **Do not create a public issue on GitHub.**
2. Email your findings directly to `security@asymm.systems`.
3. Include:
   - Detailed description of the potential vulnerability.
   - Steps to reproduce or sample test vector triggering unexpected verification behavior.
   - Any proposed remediation.

We commit to acknowledging your disclosure within 24 hours and providing an evaluation and timeline within 72 hours.
