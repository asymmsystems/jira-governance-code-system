# Security policy

## Supported versions

The latest release of this verifier is supported. It verifies evidence exported by LedgerSeal for Jira Cloud (evidence format `ledgerseal-evidence/1`).

## Reporting a vulnerability

If you find a problem in the verifier, in its canonical JSON code, or in how it checks signatures:

1. Do not open a public issue.
2. Email `security@asymm.systems` with a description, the steps or the evidence file that shows the problem, and any fix you suggest.

We acknowledge a report within 72 hours, as stated on https://asymm.systems/support.
