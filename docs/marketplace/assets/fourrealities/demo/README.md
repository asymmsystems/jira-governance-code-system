# FourRealities demo video

File: `fourrealities-demo.mp4` (89.3 seconds).

## What it shows

1. Test issue LSP-3 shows the four checks: Intent missing, Process missing, Code not used, Audit found, and Alignment 33%.
2. See all findings opens the panel: the first gap, the next step, and what the fix adds.
3. Gate findings list each check with its state and its source, then the issue's Reality Alignment Index (RAI).
4. The project dashboard for LSP: audit readiness and one card per check.
5. Coverage at a glance: the average RAI, the rated scope, the weekly change and the risk counts.
6. Issue triage: each issue with its four checks, its alignment and its top finding.

Frames: `frame-01-issue-checks.png`, `frame-02-gate-findings.png`, `frame-03-dashboard.png`, `frame-04-reality-alignment-index.png`.

## How it was made

- Date: 2026-11-09.
- Build: the development build of the app on the development site asymmsystems.atlassian.net. The "DEV" or "Dev" badge in the frames marks it. The exact build version was not recorded at the time of recording.
- Data: test projects and test issues only.
- Recording: a real screen recording (GNOME Shell Screencast), cropped to the page, cut to remove loading time, with a caption bar. H.264, 1904x920, constant 60 fps.
- Pointer: the teal pointer is a page overlay added for the recording. The browser automation's own pointer and border were hidden from the page during the recording, and the system pointer is not shown.
