# Atlassian Marketplace Listing: FourRealities for Jira

## Tagline
Cross-Reality Architecture & Delivery Integrity Dashboard for Jira and Confluence. Runs on Atlassian with zero external servers.

## Key Capabilities
- **Cross-Reality Audit**: Align what was planned in Confluence with what was tracked in Jira, committed in Git, and verified by compliance gates.
- **M11 Architecture Drift**: Track the percentage of completed issues with verifiable links to Architecture Decision Records (ADRs).
- **M29 Code Review Compliance**: Guarantee that no code bypasses mandatory peer review before issue completion.
- **M30 Rework Loop Detection**: Identify tickets bouncing repeatedly through review cycles to uncover requirements bottlenecks.
- **Composite Reality Alignment Index (RAI)**: Executive high-level score (0–100%) providing instant visibility into delivery health.
- **Seamless Suite Integration**: Directly aggregates LedgerSeal cryptographic audit seals and DefinitionGuard checklists.

## Runs on Atlassian
FourRealities is built natively on the Atlassian Forge platform.
It carries the official "Runs on Atlassian" badge:
- Zero customer data leaves your Atlassian Cloud site.
- No external databases, external compute nodes, or third-party webhooks.
- Complies natively with enterprise SOC 2, ISO 27001, and GDPR standards.

## Security
- **Data Residency**: Stored strictly within Atlassian Forge encrypted app storage.
- **Zero Egress**: Manifest strictly defines zero external endpoints. No data can leave the Atlassian cloud.
- **Least Privilege**: Restricted to `read:jira-work` and `storage:app`.
- **Static Analysis**: 100% automated test coverage with strict branch coverage enforcement.
