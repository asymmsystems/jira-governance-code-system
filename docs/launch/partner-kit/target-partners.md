# Target Atlassian Solution Partners: regulated industries and migration

Internal, for the owner. Prepared 2026-11-08 from Atlassian's public partner directory (https://partnerdirectory.atlassian.com/) and partners' own public pages. No one on this list has been contacted. The owner decides on every contact.

Method: every Platinum and Global Alliance profile and 17 Gold profiles were read; other Gold and Silver partners were screened on their directory card text only. The tier, the location and the specialization badges are as each profile showed them on 2026-11-08. The reason is a fact from the partner's public page. No personal names or contact details are kept here.

Specialization codes: SM = Service Management, CM = Cloud Migration, ESP = Enterprise Strategy and Planning, SD = Software Development.

Notes on the evidence:

- The directory's industry tags are broad (for example Financials). No profile had a "Life Sciences" tag. The GxP evidence is limited to Eficode's blog and the pharma or life sciences mentions in partners' own text.
- No profile mentions Isolated Cloud.
